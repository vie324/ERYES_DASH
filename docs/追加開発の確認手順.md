# 追加開発（依頼10〜23）の確認手順

2026-11-26 の「ENiアプリ Claude Code用プロンプト（残りすべて）」の依頼10〜23をまとめて作ったものです。
**依頼ごとに1つのコミット**に分けてあるので、1つずつ触って確かめ、フィードバックできます。

- アプリの中の確認画面：**`/staff/review`**（管理者・幹部・店舗の管理者）
  依頼ごとに「試す画面へのリンク・確かめるところ・OK／直してほしい／質問・ひとこと」があり、
  **「まとめてコピー」で文にして、そのまま開発の担当に送れます**（書いた内容はその端末にだけ残ります）。
- 設定の入口：**`/admin/features`**（管理者）。定時実行の「今すぐ実行」もここ。

## 3. 本番に出すとき（酒井さん向け）

### 3-1. 追加した環境変数（すべて任意。未設定でも画面はエラーにならず、その機能だけ止まる）

| 変数 | 用途 |
|---|---|
| `DEMO_MODE` | `1` で見本のデータで動く（**Preview にだけ**入れる。本番には入れない） |
| `AI_TOOLS_MODEL` | Wiki検索・今週やることのモデル。未設定なら `AI_SHIMON_MODEL` と同じ（キーは今の `ANTHROPIC_API_KEY`） |
| `SALONONE_API_BASE`・`SALONONE_API_KEY` | SalonOne のAPI（仕様が届いてから） |
| `CLOUDFLARE_ACCOUNT_ID`・`CLOUDFLARE_STREAM_TOKEN`・`CLOUDFLARE_STREAM_CUSTOMER_CODE` | 動画の配信（推奨の Cloudflare Stream） |
| `SUPABASE_VIDEO_BUCKET` | Cloudflare を使わないときの Supabase Storage のバケット名（初期値 `curriculum-videos`・非公開） |
| `INSTAGRAM_APP_ID`・`INSTAGRAM_APP_SECRET` | Instagram の連携 |

既存の `CRON_SECRET` が本番に入っているか確かめてください（定時実行の認証。新しい `/api/cron/daily` も使います）。

### 3-2. データベース（追加だけのマイグレーション）

- ファイル：`supabase/migrations/20261126_requests_10_23.sql`（`supabase/schema.sql` の最後にも同じものを足してあります）
- 新しいテーブル60個を作るだけで、既存のテーブル・列・データは変えません。何度流しても同じ結果です
- Postgres（PGlite）で `schema.sql` 全体を2回流して通ることを確かめてあります

手順：

1. **ステージングで確かめる**：いまは本番の Supabase しかないので、Supabase で検証用のプロジェクトを作り（または Supabase の Branching）、
   `supabase/schema.sql` を全部流す → Preview の環境変数をその検証用のプロジェクトに向けて（`DEMO_MODE` は外す）、`/staff/review` の順に触る
2. 問題がなければ、本番の Supabase の SQL Editor で `supabase/migrations/20261126_requests_10_23.sql` を流す
3. `/admin/features` を開き、「データベースにまだ無いテーブルがあります」の帯が消えていれば完了

> 本番DBへのマイグレーション・本番の環境変数は、CLAUDE.md の決まりどおり、まだ流していません。

### 3-3. 定時実行（vercel.json）

`/api/cron/daily` を日本時間 3・5・7・9・10・12・19・20・21時に1日1回ずつ登録しました。それぞれの回で「やる時刻を過ぎた仕事」を1日1回だけ行います
（同じ仕事は `job_runs` で二重にしない）。Vercel の無料プランでは時刻が1時間の中でずれることがあります。

## 4. 依頼21：中さんのClaudeにつなぐ（MCP）

1. `/admin/mcp` を開き、表示されている URL（`https://（本番のドメイン）/api/mcp`）を控える
2. 中さんの Claude で「設定 → コネクタ → カスタムコネクタを追加」を開き、名前「ENiスタッフアプリ」・URL を入れて追加
   （Team／Enterprise のプランでは、組織の管理者がコネクタを追加する画面のことがあります）
3. 「連携する」を押すと、このアプリの **許可の画面** が開く → 中さん（代表）のアカウントで「許可する」
4. チャットで「今月の練習時間を人ごとに教えて」「先月と今月の売上の推移は？」などと聞く → `/admin/mcp` の「読んだ記録」に残る

- 読めるもの：スタッフ一覧と所属・役割／売上の推移（日報の数字）／練習時間／稼働率／日報・週報の提出／ルーティン業務の達成率／目標と進み具合
- 読むだけ（書き込みのツールは無い）。お客様の個人情報・日報の文章・ログインIDは返さない
- OAuth を使えないところ（Claude Code・APIのMCPコネクタ）では、`/admin/mcp` で代表が出す「秘密のトークン」を `Authorization: Bearer …` で使える
- 許可のあとの戻り先は claude.ai／claude.com／手元のPCだけ（`/admin/mcp` で足せる）

## 5. 依頼22：Instagram（Metaのアプリの準備）

> この環境からは Meta の開発者のドキュメント（developers.facebook.com）を開けなかったため、
> 数字の名前（メトリクス）は分かっている範囲の初期値です。**管理画面 `/admin/instagram` で直せます**。
> 審査の前に、最新のドキュメントの名前と見比べてください。使えない名前は、その数字だけ飛ばして画面に出ます。

1. Meta の開発者の画面でアプリを作る（Instagram API with Instagram Login を使う種類）
2. 「Instagram → Instagramログインによる API の設定」にある **Instagram のアプリIDとシークレット** を `INSTAGRAM_APP_ID`・`INSTAGRAM_APP_SECRET` に入れる
3. ビジネスログインの設定に、`/admin/instagram` に出る3つのURL（リダイレクトURI・アンインストールのコールバック・データ削除のリクエスト）を登録
4. 権限：`instagram_business_basic`・`instagram_business_manage_insights`
5. **審査の前は「Instagramテスター」に追加した人だけ** がつなげる（アプリの役割 → Instagramテスター → 本人がInstagramの設定で招待を承認）
6. スタッフは Instagram をプロアカウント（クリエイター・ビジネス）に切り替えてから、アプリの `/staff/instagram` で「つなぐ」
7. 審査（アプリレビュー）で用意するもの：プライバシーポリシーのURL、つなぐ→数字を見るまでの画面の録画、数字の使い道の説明（スタッフ本人と幹部が見る・外に出さない）

## 6. 依頼20：動画の置き場所（比べた結果と推奨）

| | Cloudflare Stream（**推奨**） | Mux | Supabase Storage |
|---|---|---|---|
| 費用（目安） | 保存1,000分あたり月$5・配信1,000分あたり$1ほど | 小さな規模では割高になりやすい | 今の契約の中（容量・転送量しだい） |
| 持ち出しの防ぎやすさ | HLS（細切れ）＋期限つきの署名トークン。ダウンロードは既定で無効 | 似た仕組み | 期限つきURLだが MP4 なので、URLが生きている間は保存できてしまう |

- Cloudflare：Stream の画面で API トークン（Stream の編集）・アカウントID・カスタマーコード（`customer-xxxx.cloudflarestream.com` の xxxx）を環境変数に入れる
- 未設定の間は Supabase Storage の非公開バケットで配信し、どちらも無いデモでは試し用のURLで動く（画面に「保護されていません」と出る）
- 画面録画は Web では止められないため、再生中は見ている人の名前と日付を薄く重ね、ときどき位置を変えます
- 料金は変わることがあるので、契約の前に各社の料金ページで確かめてください
