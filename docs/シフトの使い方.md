# シフトの使い方（説明用まとめ）

スタッフ・管理者に「シフトまわりの使い方」を説明するためのまとめです。
ENi・EREYS 共通です（画面は同じです）。2026年9月27日時点の画面にもとづいています。

---

## 30秒でわかる要点

- シフトまわりの画面は **2つ** あり、別々に動いています。
  - **① 出勤スケジュール** …… 「誰が・何日に・何時から何時まで出勤か」。メニューの「出勤スケジュール」（ホームのアイコンでは「シフト」）。
  - **② シフト管理（3店舗・早番／遅番）** …… 「どの日に・どの店舗に・早番／遅番で誰が入るか」を自動で割り振る仕組み。画面上は「旧シフト機能」と書かれています。スタッフはホームのお知らせ「◯月分のシフト希望を提出してください」から入ります。
- **2つはつながっていません。** ①に出した希望休は②に入らず、②に出した休み希望も①には入りません。**休み希望をどちらで集めるかを、お店で1つに決めて伝えてください**（→ [5. お店で決めておくこと](#5-お店で決めておくこと)）。
- 休み希望は **3ヶ月先の分を、毎月5日までに** 出します（例：9月5日までに12月分）。お客様の2ヶ月先のご予約を確保するためです。
- スタッフがやることは「休みたい日をタップ → 理由をひとこと（有休ならチェック）→ 保存」だけです。

| | ① 出勤スケジュール | ② シフト管理（旧シフト機能） |
|---|---|---|
| 決めること | スタッフごとの毎日の出勤／休みと時間 | 日ごと・店舗ごとの早番／遅番の担当 |
| 組み方 | 曜日ごとの基本パターン＋希望休＋管理者の個別調整で、自動で決まる | 希望を集める → 自動割当（下書き）→ 手で調整 → 確定して公開 |
| 店舗・早番／遅番 | なし | あり |
| スタッフの入口 | メニュー「出勤スケジュール」／ホームの「シフト」 | ホームのお知らせ「◯月分のシフト希望を提出してください」／出勤スケジュール画面のいちばん下「旧シフト機能（早番・遅番）はこちら」 |
| 管理者の入口 | メニュー「出勤スケジュール」 | 出勤スケジュール画面のいちばん下「旧シフト機能（早番・遅番の自動割当）はこちら」 |
| スタッフに見えるタイミング | 保存した瞬間から全員に見える（下書き・確定の段階はない） | 管理者が「確定」するまで見えない |

## 1. 【スタッフ】① 出勤スケジュール

### 1-1. 出勤予定を見る

1. メニュー（右下の「メニュー」）→「出勤スケジュール」を開きます。ホームの「シフト」からも開けます。
2. 月ごとの表が出ます。日付のすぐ右が自分の列（名前のあとに「（自分）」）で、横にスクロールすると他のスタッフも見られます。
3. 表の見方
   - `10:00-16:30` …… 出勤（時間つき）
   - `出勤` …… 出勤（時間の指定なし）
   - `休` …… 休み。`休 希` は希望休で休みになった日です
   - 小さい文字のメモ（例：研修・時短）…… 管理者が個別に調整した日
4. 月は上の「‹ ›」で切り替えます。

### 1-2. 希望休を出す（毎月5日まで・3ヶ月先の分）

1. 「出勤スケジュール」の上にある **「希望休を申請する」** を押します。
2. 上の「‹ ›」で申請する月を選びます。**「この月の締切：◯年◯月◯日 まで」** と出ていれば申請できます。
   - ⚠ 毎月6日以降に開くと、最初は締切を過ぎた月（「締切（…）を過ぎたため変更できません」）が表示されます。**「›」で次の月へ進めば申請できます。**
   - 締切前の月なら、もっと先の月の分を早めに出しておくこともできます。
3. カレンダーで **休みたい日をタップ** します（「休」と出ます。もう一度タップで取り消し）。
4. 下に出る **「休み希望の理由・有休」** に、日ごとの理由をひとこと書きます（例：友人の結婚式、通院、家族の予定）。
   - 理由は、同じ日に休み希望が重なったときに、どちらを優先するかを決める材料になります。
   - **有休で休みたい日は「有休」にチェック** します（カレンダーの表示が「有休」になります）。スタイリストの有休も、ここで休み希望と一緒に申請します。
5. **「この内容で申請する（上書き保存）」** を押します。「◯年◯月の希望休を保存しました」と出れば完了です。
   - 締切までは何度でも直せます。保存するたびに、その月の希望休がまるごと今の内容に置きかわります（選択を外して保存すると、その日は取り消されます）。
   - 月ごとに保存が必要です。保存せずに月を切り替えると、選んだ日は消えます。

**知っておくこと**

- 定休日や、もともと休みの曜日は申請不要です（基本パターンで自動で休みになります）。
- 休みの日数に上限はありません。他の人と重なっても、その場で止められることはありません（管理者が理由を見て調整します）。
- 出した希望休は、保存した瞬間に表で「休 希」になり、**他のスタッフからも「希望休の日」として見えます**（理由と有休かどうかは管理者にだけ見えます）。
- 締切を過ぎてからの変更は、お店（管理者）に相談してください。管理者が「個別調整」で変えられます。

### 1-3. お知らせ

- 毎月1日〜5日の間、その月の締切分（3ヶ月先の月）の希望休を1日も出していない人には、メニューの「出勤スケジュール」とホームの「シフト」に「！」が付き、タスクの「今日のやること」に「◯月の希望休が未提出です」と出ます。
- 休みが要らない月でも、5日までは「！」が出たままになります（1日も出していない＝未提出、と数えるため）。

## 2. 【管理者】① 出勤スケジュール

### 2-1. 最初に1回：基本パターンを登録する

1. メニュー →「出勤スケジュール」→ **「基本パターンの設定」** を開きます。
2. スタッフごとに、日〜土の各曜日の「出勤」にチェックを入れ、開始〜終了の時間を入れます。
   - 休みの曜日・定休日は **「出勤」のチェックを外す** だけです。
   - 時間を空けたまま出勤にすると、表では「出勤」とだけ出ます。
3. **「◯◯さんのパターンを保存」** を押します（1人ずつ保存します）。

**注意**

- パターンを登録していないスタッフは、毎日「休」になります。新しく入った人は最初に登録してください。
- パターンを変えると、**過去の月も含めてすべての月の表示が新しいパターンで出し直されます**（パターンの履歴は持っていません）。過去の出勤を残したい日は、個別調整で上書きしておいてください。

### 2-2. 毎月：希望休を確認する

1. 「出勤スケジュール」の **「希望休の提出状況（◯年◯月分・締切 ◯月◯日）」** に、スタッフごとの希望休の日数が出ます。
   - 0日は「未提出」と「休みが要らない」の区別がつきません。気になる人には声をかけてください。
2. 表で月を切り替えると、希望休の日は「休 希」、その下に「希望休（有休）：理由」が出ます。
3. 同じ日に休みが重なっているときは、理由を見て、次の個別調整で決めます。

### 2-3. 個別調整（休み⇔出勤・時間の変更）

1. 表の **変えたいマスをタップ** します。
2. 「現在の予定：…（個別調整／希望休／基本パターン）」を確認し、「この日の勤務」で「出勤」か「休み」を選びます。出勤なら開始〜終了の時間も入れます（「休み」を選ぶと時間は保存されません）。
3. 必要なら「メモ（任意・表に小さく表示されます）」に書きます（例：研修、時短、振替休）。
4. **「この内容で上書きする」** を押します。表では黄色の太字になります。
5. 元に戻すときは、同じマスを開いて **「個別調整を取り消す」** を押すと、基本パターン・希望休どおりに戻ります。

**決まり方（優先順位）**

> 個別調整（管理者） ＞ 希望休（スタッフ） ＞ 曜日ごとの基本パターン

- 希望休を管理者が消す画面はありません。休みを取りやめてもらうときは、その日を個別調整で「出勤」にします（スタッフの希望休の画面には、その日が選ばれたまま残ります）。
- 有休は「有休」と表示されるだけで、残日数の管理や承認はアプリではしていません。

## 3. 【スタッフ】② シフト希望の提出（3店舗・早番／遅番）

1. ホームのお知らせ **「◯年◯月分のシフト希望を提出してください（締切：◯月◯日）」** を押します。
   - お知らせは、その月の希望を出すまでホームに出続けます（締切の前の月の15日〜締切日は目立つ色になります）。
   - 「出勤スケジュール」画面のいちばん下「旧シフト機能（早番・遅番）はこちら」→「◯年◯月の希望を提出する」からも開けます。
2. **「休みたい日（希望休）」** で、休みたい日をタップします（「休み」と出ます。もう一度タップで取り消し）。
   - **選んでいない日は「勤務できる日」の扱い** になります。
3. **「休み希望の理由・有休」** に理由をひとこと。有休の日は「有休」にチェックします（①と同じ）。
4. **「この月に勤務できる店舗（複数選択可）」** で、入れる店舗を選びます。**選んだ店舗にだけシフトが組まれます。**
5. 伝えたいことがあれば「備考（任意）」に書きます（例：20日は通院のため午前のみ可です）。
6. **「この内容で提出する」** を押します。「提出しました。締切までは何度でも修正できます。」と出れば完了です。
7. 管理者がシフトを確定すると、②の「シフト」画面に **「あなたのシフト」**（日付・早番／遅番・店舗）が出て、**「全体シフトを見る（誰がどの店舗か）」** で全員分も見られます。確定するまでは「この月のシフトは調整中です」と出ます。
   - ②の「シフト」画面は、「出勤スケジュール」画面のいちばん下「旧シフト機能（早番・遅番）はこちら」から開きます。**ホームの「シフト」アイコンは①の出勤スケジュールにつながっている** ので、まちがえないように伝えてください。

- 提出した内容は、本人と管理者だけが見られます。
- **希望を出さなかった人は、自動割当で1日もシフトに入りません**（管理者が手で入れることはできます）。店舗を1つも選ばなかった場合も同じです。

## 4. 【管理者】② シフト管理（自動割当 → 調整 → 確定）

入口：メニュー →「出勤スケジュール」→ いちばん下の「旧シフト機能（早番・遅番の自動割当）はこちら」→ **「シフト管理」**。

### 4-1. 最初に1回：ルール設定

「シフト管理」→ **「ルール設定（連勤上限・最低人数・締切日）」**

| 項目 | 既定 | 意味 |
|---|---|---|
| 連勤の上限（日） | 5 | 自動割当はこの日数を超えて続けて入れません（前の月からの続きも数えます） |
| 各店舗・各日の最低人数（名） | 2 | 1日単位の人数（早番・遅番ごとではありません）。足りない日はボードで赤く警告されます |
| 何ヶ月先の分を募集するか | 3 | 3なら「9月5日までに12月分」 |
| 希望提出の締切日（◯日） | 5 | 上とセットで締切が決まります |

- 「保存する」で「保存しました（次回の自動割当から反映されます）」と出ます。
- ここの「何ヶ月先・締切日」は②だけに効きます。①の希望休は「3ヶ月先・5日締切」で固定です。

### 4-2. 希望の集まり具合を見る

- 「シフト管理」を開くと、いま募集中の月が出ます（締切を過ぎた、これから組む月は「‹」で前の月へ戻ります）。
- 「希望の提出状況（提出人数／在籍人数・締切）」「未提出：◯◯、…」「シフトの状態（未作成／下書き／確定済み）」が並びます。
- 下の「提出された希望」で、1人ずつ「勤務可能店舗」「休み希望（有休）」「休みの理由」「備考」を確認できます。

### 4-3. 自動割当で下書きを作る

1. **「割当ボードを開く（自動割当・調整・確定）」** を押します。
2. **「自動割当を実行（下書きを作り直す）」** を押すと、下書きができます（この時点ではスタッフには見えません）。
3. 自動割当は、休み希望・勤務できる店舗・連勤の上限・最低人数を守ったうえで、次の考え方で組みます（ボードにも同じ説明が出ます）。
   - スタイリストの休みを先に決める（希望休を優先。平日の調整休みはスタイリスト同士で別の日に。3段同士は必ず別）
   - 各店舗にスタイリストを均等に置き、アシスタントは「スタイリストの段数の合計 〜 ＋2人」を目安に入れる
   - それ以上に人が余る日は「有休候補」として下に出す
   - しもん塾・全体会議など全員参加の日は、出られる人を全員出勤にする
   - 幹部会議など会議のある日は、参加者を休みにしない（「ミーティング・議事録」に登録された会議で判断します）
   - 土日はなるべく出勤。休みになるなら段数の少ない人（1段）から。平日は、土日が連勤上限にかからないよう調整する
   - 段数の多いスタイリストが休む日は、年数の高いアシスタント（ファイナル・ミドル）も休みに寄せる
4. 職種（スタイリスト／アシスタント）・段数・ランク・所属店舗は、マスタ設定のスタッフ情報を使います。職種が未設定の人はアシスタントとして扱います。

⚠ **自動割当をやり直すと、今の下書きも、手で直したところも全部消えます。** 手で直す前に実行してください。

### 4-4. 手で調整する

- 表は「日付 × 店舗」。マスの中に「姓 早／遅」が並びます。
- 消すとき：名前の横の「×」（確認なしですぐ消えます）。
- 足すとき：マスの「＋追加」→ 下の「割当を追加（手動調整）」で日付・早番／遅番・スタッフ・店舗を選んで **「追加する」**。
- 店舗や早番／遅番を変えたいときは、「×」で消してから追加し直します。
- 休み希望の日や、選ばれていない店舗にも入れられますが、印と警告が付きます（最終判断は管理者）。

**警告の見方**（ボードの上にまとめて出ます）

- 赤：人数不足（最低人数に届かないマス。表でも赤）／休み希望の日に割当がある／連勤の上限を超えている
- 赤の太字：3段のスタイリスト同士の休みが重なっている
- 黄：スタイリストの休みが重なっている／その店舗にスタイリストがいない／会議の参加者が休みになっている／勤務できる店舗の外（または希望未提出）に入っている
- 青：人が余っている日（有休を使ってもらう相談の目安）

※ 店舗の定休日という考え方はないため、誰も入れない日も「人数不足」として赤く出ます。

### 4-5. 確定して公開する

1. 警告を見て直し終わったら、**「内容を確認しました。確定すると全スタッフに公開されます。」** にチェックを入れて、**「この月のシフトを確定する」** を押します。
2. 「シフトを確定しました（◯件）。全スタッフが閲覧できます。」と出れば完了です。
3. 確定したあと
   - 表からの追加・削除は、**その場ですぐ公開** されます。
   - 自動割当のやり直しはできません。確定の取り消しもありません。
   - 変えたことはアプリからは通知されないので、本人に直接伝えてください。

## 5. お店で決めておくこと

**休み希望をどちらで集めるかを1つに決めて、スタッフに伝えてください。** 2つはデータがつながっていないので、両方に出してもらうと手間が倍になり、片方にしか出していない人の休みが抜けます。

- 「誰が何日に出勤するか」が決まればよい → **①の希望休** で集めます。
  - スタッフのホームには②のお知らせ（「シフト希望を提出してください」）が出続けます。「こちらは使っていない」と伝えておいてください。
- 店舗・早番／遅番の割り振りまでアプリで決めたい → **②のシフト希望** で集めます。
  - このとき①の「出勤スケジュール」の表は②の結果とは連動しません。スタッフには「確定したシフトは、出勤スケジュール画面のいちばん下『旧シフト機能（早番・遅番）はこちら』の『あなたのシフト』『全体シフト』で見る」と伝えてください。

## 6. 締切とお知らせの流れ（例：2026年9月〜10月）

| 日付 | ① 出勤スケジュール | ② シフト管理 |
|---|---|---|
| 9月5日(土) | 12月分の希望休の締切 | 12月分のシフト希望の締切 |
| 9月6日〜 | 12月分は締切済み。管理者が出勤スケジュールを整える | 管理者が12月分を自動割当 → 調整 → 確定 |
| 9月15日(火) | ― | ホームのお知らせが目立つ色に（1月分の募集） |
| 10月1日(木)〜5日(月) | 1月分を1日も出していない人に「！」 | ホームのお知らせ（未提出の人） |
| 10月5日(月) | 1月分の希望休の締切 | 1月分のシフト希望の締切 |

- 2026年9月27日時点で受付中なのは **2027年1月分（締切10月5日(月)）** です。12月分は9月5日で締め切っています。
- ②には「毎月15日 10:00 に募集のお知らせを自動で送る」仕組みがありますが、**送り先（LINE・メールなど）がまだつながっていないため、実際には誰にも届きません。** お知らせはホームの表示だけです。

## 7. よくある質問

**Q. 希望休の画面を開いたら「締切を過ぎたため変更できません」と出た**
A. 毎月6日以降は、最初に締切済みの月が開きます。上の「›」で次の月に進めば申請できます。

**Q. 締切を過ぎてから休みを変えたい**
A. ①は管理者の「個別調整」で変えます。②は管理者が割当ボードで入れ替えます。どちらもお店（管理者）に相談してください。

**Q. 有休はどう申請する？**
A. 休み希望と一緒に、その日の「有休」にチェックします。アプリでは「有休」と表示するだけで、残日数の管理や承認はしていません。

**Q. 新しく入った人が毎日「休」になっている**
A. ①の基本パターンがまだ登録されていません。管理者が「基本パターンの設定」で登録してください。

**Q. ②で自分のシフトが1日も入っていない**
A. その月のシフト希望を出していないか、「勤務できる店舗」を1つも選んでいない可能性があります。管理者に確認してください。

**Q. ②を確定したあとに直したい**
A. 割当ボードで「×」と「＋追加」で直せます（すぐ公開されます）。自動割当のやり直しや、確定の取り消しはできません。

**Q. 幹部も調整できる？**
A. シフトまわりの調整（基本パターン・個別調整・割当ボード）は管理者アカウントだけです。

## 8. 説明するときの文面（コピーして使えます）

**スタッフ向け（①で希望休を集める場合）**

```
【希望休のお願い】
◯月分の希望休を、◯月5日までにアプリで出してください。
メニュー →「出勤スケジュール」→「希望休を申請する」
→ 月を「◯月」に合わせる → 休みたい日をタップ
→ 理由をひとこと（有休の日は「有休」にチェック）
→「この内容で申請する」
締切までは何度でも直せます。締切後の変更はお店に相談してください。
```

**スタッフ向け（②でシフト希望を集める場合）**

```
【シフト希望のお願い】
◯月分のシフト希望を、◯月5日までにアプリで出してください。
ホームの「◯月分のシフト希望を提出してください」を押す
→ 休みたい日をタップ（理由をひとこと・有休はチェック）
→「この月に勤務できる店舗」を選ぶ
→「この内容で提出する」
出さないと自動でシフトが組まれないので、休みがなくても必ず提出してください。
確定したシフトは、メニュー →「出勤スケジュール」→ いちばん下の
「旧シフト機能（早番・遅番）はこちら」で見られます。
```
