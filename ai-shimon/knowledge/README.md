# AIしもん 知識ファイルの置き場所

しもん側から送られてくる `02_知識ファイル/01〜14`（12ファイル）を **このフォルダにそのまま入れて**ください。
中身は編集せず、更新のときはファイルごと差し替えます（正本はしもん側で管理）。

- ファイル名は送られてきたままでOKです。先頭の2桁の番号（`01_…` 〜 `14_…`）で識別します
- 拡張子は `.md`（または `.txt`）
- このフォルダはサーバー側でしか読まれません。スタッフの画面にファイル本体が出ることはありません
- **`08_スタッフ欲求プロファイル.md` は要配慮情報です。** AIへの入力にしか使わず、画面・ログには出しません
- ファイルが1つも無くても AIしもん は動きます（システムプロンプトだけで応答。知識は薄くなります）

## 番号ごとの使われ方

| 番号 | 使われ方 |
|---|---|
| 02・04・07・08 | 毎回の会話で必ず渡す「土台」（プロンプトキャッシュが効く） |
| 01・03 | 部下・後輩の育成の話題（どの話題にも当てはまらないときのフォールバックでもある） |
| 09 | 自分自身の成長・目標の話題 |
| 10・14 | 接客・お客様・クレームの話題 |
| 11 | カリキュラム・技術の話題 |
| 12 | しもん個人についての話題 |
| 13・14 | 仕組み・設計・店販・集客の話題 |

どの番号がまだ置かれていないかは、管理者画面の「マスタ設定 → AIしもん」で確認できます。
