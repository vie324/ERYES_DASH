# AIしもん 知識ファイルの置き場所

しもん側から送られてくる `02_知識ファイル/01〜17`（17ファイル）を **このフォルダにそのまま入れて**ください。
中身は編集せず、更新のときはファイルごと差し替えます（正本はしもん側で管理）。

- ファイル名は送られてきたままでOKです。先頭の2桁の番号（`01_…` 〜 `17_…`）で識別します
- 拡張子は `.md`（または `.txt`）
- このフォルダはサーバー側でしか読まれません。スタッフの画面にファイル本体が出ることはありません
- **`08_スタッフ欲求プロファイル.md` は要配慮情報です。** AIへの入力にしか使わず、画面・ログには出しません
- ファイルが1つも無くても AIしもん は動きます（システムプロンプトだけで応答。知識は薄くなります）

## 番号ごとの使われ方

| 番号 | 使われ方 |
|---|---|
| 02・04・06・07・08・15 | 毎回の会話で必ず渡す「土台」（プロンプトキャッシュが効く） |
| 01・03 | 部下・後輩の育成の話題（どの話題にも当てはまらないときのフォールバックでもある） |
| 09 | 自分自身の成長・目標の話題 |
| 10・14 | 接客・お客様・クレームの話題 |
| 11 | カリキュラム・技術の話題 |
| 12・16 | しもん個人についての話題 |
| 13・14 | 仕組み・設計・店販・集客の話題 |
| 17 | ENi固有語（幸業績・自創・継承者・ボイスチェンジ など）が出てきたとき |
| 05 | 全体宛LINEの言い回し（いまは話題ぶんの振り分け先にしていない予備） |

`06`（1対1DMの言い回し）と `15`（本人の音声から抽出した実際の話し方）は**語り口の一次資料**です。
土台から外すと返答が「マイルドすぎる」方に戻るので、必ずこのフォルダに置いてください（2026-09-10のしもん側指摘）。

## 呼称（フルネームで呼ばせない）

しもんはスタッフをフルネームで呼びません。そのため、ログイン中の氏名はそのままAIに渡さず、
**`07_スタッフ呼称.md` の対応表で「しもんの呼び方」に変換してから**渡しています。

- 表に載っていない人は**下の名前だけ**を渡します
- 下の名前も分からないときだけ、「これはログイン氏名なので呼びかけに使うな」と明示して渡します
- 何人ぶん読めているかは、管理者画面の「マスタ設定 → AIしもん」で確認できます。
  ファイルを差し替えて件数が急に減ったときは、表の書式が変わった可能性があります

どの番号がまだ置かれていないかも、同じ「マスタ設定 → AIしもん」で確認できます。
