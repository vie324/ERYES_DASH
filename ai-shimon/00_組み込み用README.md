# AIしもん 組み込み用ソース一式（2026-09-10 改訂版）

ENiの自社システムに組み込む「AIしもん」（代表しもんの分身として全スタッフが壁打ちできるAI）のソース一式です。

## ★今回の改訂で直したこと（2026-09-10）

スタッフに開放したあと、実際の会話を見て**しもん本人から複数の指摘**が出ました。**8月28日にお渡しした版から中身が変わっています。差し替えをお願いします。**

### 1. 全員が「フルネーム」で呼ばれてしまっている ← **実装側の対応もお願いしたい**

システムがログイン情報の氏名（例：`高橋未来`）をそのままAIに渡しているため、AIが「**高橋未来さん、話してくれてありがとう**」と呼んでいます。

**しもんはスタッフをフルネームで呼ぶことが絶対にありません。** 必ず下の名前かあだ名です（未来ちゃん／ゆうと／けいしゅう）。

プロンプト側にも「フルネームで呼ばない」ルールを最優先で入れましたが、**実装側で次のどちらかをしていただけると確実です**：

- **（推奨）呼び名に変換してから渡す。** `02_知識ファイル/07_スタッフ呼称.md` の対応表で、ログイン氏名 →「しもんの呼び方」に変換し、その値だけをプロンプトに渡す
- **（次善）フルネームだと明示して渡す。** 例：`【相談者】ログイン氏名=高橋未来（※これはシステム上の氏名。呼びかけには使わず、呼称表で呼び名に変換すること）`

**そのまま氏名だけを渡す形は避けてください。** モデルは渡された文字列をそのまま呼びかけに使う傾向があります。

### 2. 「俺も昔そうだったよ」が多すぎた

自己開示が毎回の返答に出ていました。**1つの相談で多くて1回**に制限するルールへ変更しています（`01_システムプロンプト.md`）。

### 3. 共感が「なるほど」一辺倒でマイルドすぎた

本人の指定で、相談の入り口に**素の共感**（「わかるなーそれ」「それはしんどいよな」）を置くルールを追加しました。

### 4. 語り口の一次資料が渡っていなかった ← **今回いちばん大きい修正**

これまで語り口の根拠が「LINEの文字データ」だけで、**しもん本人が実際に喋っている音声データを一度も使っていませんでした**。これが「全部ちょっとマイルドで優しい感」の原因です。

今回、**音声逐語74ファイルから話し方を抽出した知識ファイルを新規追加**しました（`15_しもんの実際の話し方.md`）。あわせて、これまで漏れていた実測データ（`05`・`06`）と、ENi固有語の辞典（`17`）も追加しています。

### 5. 呼称表そのものに誤りがあった

しもん本人の確認で2点直しています（`02_知識ファイル/07_スタッフ呼称.md`）。

- **岸京秀さんの呼び名は「けいしゅう」**（8/28版に「ケイシュ」と入っていた場合は差し替えてください）
- **「みなちゃん」という人は実在しません。** 音声の文字起こしの誤変換でした。前の版にこの名前が入っていた場合は必ず差し替えてください
- 大田空さんの姓は**「大田」**です（文字起こしでは「太田」と出ますが誤りです）

### 6. 一式の作り方を変えました（今後の差し替えが楽になります）

これまでは原本から手でコピーしてこの一式を作っていたため、**原本を直しても送付ファイルに反映されない**ことが起きていました（今回の「引き継ぎソースが足りていない」の正体です）。

## プロンプトの組み立て方

費用を抑えるため、知識ファイルは毎回全部は渡さず「土台＋話題ぶん」の2段構成にしています。

- **土台（毎回渡す）**：`01_システムプロンプト.md` ＋ 知識ファイル **`02`・`04`・`06`・`07`・`15`**（＋`08`）
  → **今回`06`と`15`を土台に追加しました。** 語り口の一次資料なので、毎回渡らないと「マイルドすぎる」が再発します
  → 毎回同じ内容なのでプロンプトキャッシュが効きます
- **話題ぶん（その時だけ）**：相談文に含まれるキーワードで選んで追加。**単純な文字列マッチで、AI呼び出しは不要**（費用ゼロ・遅延ゼロ）
- どれにも当てはまらないときは `01`・`03` を渡す（フォールバック）

## 必ず守ってほしいこと

1. **知識ファイルとAPIキーはサーバー側にのみ置く。** スタッフ側にファイル本体を送らない・ダウンロードできる形にしない
2. **AIの発話にファイル名・見出し番号・出典パスを出さない**（プロンプトに指示済みですが、UI側でも引用マーカー等が出ない構成に）
3. 利用はENiスタッフ限定。ログイン等でゲートしてください
4. **氏名の渡し方**（上記「今回の改訂1」）。ここが今回いちばんの実装側のお願いです
5. **`08_スタッフ欲求プロファイル.md` は特に厳重に。** スタッフ個人の心理診断・MBTIを含む要配慮情報です。AIが肯定・導きのトーンを本人に合わせるための**内部知識専用**で、①APIに渡す以外の用途に使わない、②管理画面等でもスタッフから閲覧できる場所に置かない、③ログ・エラー出力に本文を残さない、をお願いします
