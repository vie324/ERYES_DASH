# AIしもん 組み込み用ソース一式

ENiの自社システムに「AIしもん」（代表しもんの分身として全スタッフが壁打ちできるAI）を組み込むためのソース一式です。
現在Cloudflare Workers＋Claude APIで本番稼働しているWeb版と**同じ中身**です。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `01_システムプロンプト.md` | **本線。** システムプロンプトの土台。毎回のリクエストで必ず渡す指示文 |
| `02_知識ファイル/01〜14`（12ファイル） | AIしもんの知識。話題に応じて選んでシステムプロンプトに足す（下記「組み立て方」） |
| `02_知識ファイル/08_スタッフ欲求プロファイル.md` | **取り扱い注意（下記参照）。** スタッフ各人の欲求傾向とMBTI。肯定・導きのトーンを本人に合わせるための内部知識 |
| `03_フル版SKILL.md` | 指示文のフル版。文字数制限のない環境なら`01`の代わりにこちらを使ってもよい（内容は同系統でより詳しい） |
| `04_実装参考_worker.template.js` | 現行Web版（Cloudflare Worker）の実装。API呼び出し・キャッシュ・ストリーミングの参考に |
| `05_スタッフ向け使い方ガイド.md` | スタッフに配る利用ガイド。UIのヘルプ等に流用OK |

## プロンプトの組み立て方（現行Web版の方式）

費用を抑えるため、知識ファイルは毎回全部は渡さず「土台＋話題ぶん」の2段構成にしています。

- **土台（毎回渡す）**：`01_システムプロンプト.md` ＋ 知識ファイル `02`・`04`・`07`・`08`
  → 約2.5万字。毎回同じ内容なのでプロンプトキャッシュが効く
  ※`08`は現行Web版の土台には入っていない今回の追加分。相談者が誰でも（本人の相談でも部下の相談でも）効くので土台に置くのが簡単。システムのログイン情報で相談者本人が特定できるなら、「本人の行＋会話に名前が出た人の行だけ差し込む」形にできるとさらに良い
- **話題ぶん（その時だけ）**：相談文に含まれるキーワードで選んで追加。**単純な文字列マッチで、AI呼び出しは不要**（費用ゼロ・遅延ゼロ）
- どれにも当てはまらないときは `01`・`03` を渡す（フォールバック）

### API設定（現行の推奨）

- モデル：**Claude Sonnet**（品質優先。全体展開でコストが気になったらHaikuに落とす判断）
- `system` は「土台」「話題ぶん」の2ブロックに分け、**両方に `cache_control: {type: "ephemeral"}`** を付ける（土台はほぼ確実にキャッシュヒット）
- 実測目安：Sonnetで約8円/通、Haikuで約3円/通

## 必ず守ってほしいこと

1. **知識ファイルとAPIキーはサーバー側にのみ置く。** スタッフ側（クライアント）にファイル本体を送らない・ダウンロードできる形にしない。現行Web版もこの設計です
2. **AIの発話にファイル名・見出し番号・出典パスを出さない**（システムプロンプトに指示済みですが、UI側でも引用マーカー等が出ない構成に）
3. 利用はENiスタッフ限定。ログイン等でゲートしてください
4. **`08_スタッフ欲求プロファイル.md` は特に厳重に。** スタッフ個人の心理診断・MBTIを含む要配慮情報です。AIが肯定・導きのトーンを本人に合わせるための**内部知識専用**で、①APIに渡す以外の用途に使わない、②管理画面等でもスタッフから閲覧できる場所に置かない、③ログ・エラー出力に本文を残さない、をお願いします。AIが会話で中身を明かさないルールはシステムプロンプト側に入れてあります

## 更新について

このデータの正本はしもん側で管理しています。内容を更新したときは一式を再送しますので、**酒井さん側でファイルの中身は編集せず**、差し替えで反映をお願いします。
