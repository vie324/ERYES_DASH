# AIしもんの使い方

しもんの考え方をベースにした、**みんなの壁打ち相手**です。
一人で抱えて止まってしまう時間を減らして、次の一歩を自分で決められるようになるために作りました。

---

## どんなことを相談していいの？

**なんでも大丈夫です。** 遠慮しなくていい。

| こんなとき | 例 |
|---|---|
| 後輩・部下のことで悩んでる | 「後輩が同じミスを繰り返してて、どう言えばいいか分からない」 |
| 自分自身のことで迷ってる | 「自分がこの先どうなりたいのか分からなくなってきた」 |
| お客様への接し方 | 「店販の提案が押し売りっぽくなっちゃう」「次回予約が取れない」 |
| カリキュラム・技術の進め方 | 「テストがなかなか受からなくて心が折れそう」 |
| 仕組みづくり | 「チェック体制を作りたいけど、監視っぽくなるのが嫌」 |
| しもんのこと | 「しもんさんってどんな人？」「何を大事にしてる？」 |

**愚痴だけでも大丈夫です。** 「今日はもう疲れました」から始めてもらって構いません。

## 使い方のコツ

1. **最初に名乗ってください。** 「ゆうとです」みたいに。名前で呼び返してくれます
2. **かしこまらなくていい。** 話し言葉のままで大丈夫
3. **すぐ答えが返ってこなくても焦らない。** 質問を返してくることが多いです。それは、自分の言葉で考えを整理してもらうため
4. **「で、どう思う？」と聞かれたら、思ったままを返す。** 正解を言おうとしなくていい
5. **最後に「1週間以内にやること」を聞かれます。** そこまでやると壁打ちが完了します

## 何ができないか（正直に書きます）

**AIなので、できないこと・答えられないことがあります。** そこは正直に「分からない」と言うように作ってあります。知ったかぶりで答えられるより、そのほうが安全だからです。

- **カット・カラーの具体的な手順** — 動画や先輩に直接聞いてください
- **給与・歩合・仕入れ値** — しもんさんか幹部に直接
- **誰かの評価（「あの子ランク上げていい？」）** — 面談で本人・上司と
- **最新の経営数字・出店計画** — 変わっている可能性があるので、しもんさんに直接

## 人に相談してほしいこと（AIで抱えないでください）

以下は、AIしもんとの会話で止めずに、**必ず人につないでください。** AIしもん自身も、この話題が出たら「直接話して」と案内します。

- **心や体がしんどい**（自分のことでも、後輩のことでも）
- **ハラスメント・いじめ・お金のトラブル**
- **お客様から怖い思いをさせられた**（大声・理不尽な要求など）→ **その場ですぐ上司へ。安全が最優先です**
- **クレームが起きた** → **まず上司に報告。初動30分が勝負です。** AIに相談してから報告、では遅い
- **辞めたい／辞めさせたい**

## 覚えておいてほしいこと

**AIしもんは、しもん本人ではありません。**

しもんの考え方を学習させていますが、**言い間違い・勘違いをすることがあります。** 「しもんさんがこう言ってた」とAIが言っても、それが本当かどうかは確かめてください。おかしいと思ったら、しもんさんに直接聞いてください。

そして——**AIしもんを使うのは、人に相談しなくていいということではありません。** 一人で考える時間の相棒として使って、その先はちゃんと仲間や先輩を頼ってください。頼っていいんです。一人じゃないので。

## うまくいかなかったら

「これしもんさんっぽくないな」「答えがズレてるな」と思ったら、**しもんさんに教えてください。** そのフィードバックで直していきます。
